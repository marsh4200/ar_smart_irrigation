# Brand assets

`icon.png` / `icon@2x.png` (256×256 / 512×512) and `logo.png` / `logo@2x.png`
for the AR Smart Irrigation integration — a sprinkler head fanning three
water jets, on a blue-to-teal gradient badge.

Home Assistant itself doesn't read icons from inside a custom component; it
looks them up by domain from the community
[home-assistant/brands](https://github.com/home-assistant/brands) repo. To
have `ar_smart_irrigation`'s icon show up in **Settings → Devices & Services**
and HACS, submit these four files as a PR to that repo under
`custom_integrations/ar_smart_irrigation/`. Until then, they're just kept
here for reference and reuse (READMEs, HACS listing, your own site).
